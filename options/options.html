Whatnot Card Appraiser

Card identification

Auto-detection of a new card is always free (local frame diff). The engine only controls how a detected card is identified. Card-name OCR reads the card's name on-device (bundled Tesseract) and searches PriceCharting for it — free, no setup, works on glary stream frames where image search fails. Pick the right card from the match list to confirm.

Streams often show Japanese cards. All matches both; narrow it only if you get cross-language mismatches.

Your key is stored only in this browser's local extension storage and sent directly to Anthropic when a new card is detected. It is visible to anyone with devtools on this machine — use a dedicated, low-limit key.

Detection tuning

Lower threshold = more sensitive (more triggers). Turn on debug to watch the live diff score in the overlay footer.
