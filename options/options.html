Card identification

Auto-detection of a new card is always free (local frame diff). The engine only controls how a detected card is identified. Photo Search uses PriceCharting's own image recognition — free and no setup.

Your key is stored only in this browser's local extension storage and sent directly to Anthropic when a new card is detected. It is visible to anyone with devtools on this machine — use a dedicated, low-limit key.

Detection tuning

Lower threshold = more sensitive (more triggers). Turn on debug to watch the live diff score in the overlay footer.
